# ТВ Лад

Порядок у телевізорі **KIVI** (і будь-якому Android TV) з комп'ютера через Wi‑Fi:

- **Прискорення** — швидкі анімації, очищення кешу, вивантаження фонових програм, глибока оптимізація.
- **Програми** — вимкнути непотрібне; системне, без чого телевізор не працює, програма не чіпає.
- **Головний екран** — Projectivy Launcher без реклами замість стандартного.
- **Відновлення** — кожну зміну можна повернути одним натисканням.

## Як користуватися

1. На телевізорі: Налаштування → Налаштування пристрою → Про пристрій → 7 разів «Збірка»;
   потім «Для розробників» → «Налагодження USB» (і «через мережу», якщо є).
2. Запустіть `TVLad.exe`, натисніть «Знайти в мережі» або впишіть IP телевізора → «Підключити».
3. На телевізорі підтвердіть «Дозволити налагодження» (позначте «Завжди дозволяти»).

При першому підключенні програма завантажує офіційний `adb` від Google (≈ 7 МБ).
